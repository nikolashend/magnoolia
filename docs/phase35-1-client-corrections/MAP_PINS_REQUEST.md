# Kaardi pinnid / Пины на карте — что нужно от заказчика

**Статус сейчас:** на `/asukoht` стоит встроенная карта Google с меткой Magnoolia tee. Ниже — ряд ссылок на важные объекты (Vaela lasteaed, Kiili kool, Kiili spordihoone, IKEA, Selver, Decathlon), каждая открывает объект на карте в новой вкладке.

**Чего не хватает:** Индрек хочет, чтобы эти 6 объектов были метками **на самой карте**, рядом с Magnoolia.

---

## Почему это не сделано сразу

Встроенная карта Google без API-ключа (`output=embed`) технически умеет показывать **только одну точку** — ту, что в запросе. Это ограничение Google, а не вёрстки. Чтобы на одной карте было 7 меток (Magnoolia + 6 объектов), нужен один из двух вариантов ниже. Оба требуют действия со стороны владельца проекта, поэтому сделать это в одиночку невозможно.

---

## Вариант A — Google My Maps *(рекомендуемый)*

Бесплатно, без API-ключа, без биллинга, метки остаются под контролем заказчика.

**Что нужно сделать (≈10 минут, один раз):**

1. Зайти на **https://mymaps.google.com** под аккаунтом Google компании (не под личным — иначе карта «привяжется» к человеку).
2. **Создать новую карту** → назвать, например, `Magnoolia — asukoht ja lähiümbrus`.
3. Добавить 7 меток кнопкой «Добавить маркер»:
   - **Magnoolia tee, Vaela küla, Kiili vald** ← основная, желательно выделить цветом/иконкой
   - Vaela lasteaed
   - Kiili kool (Kiili Gümnaasium)
   - Kiili spordihoone (Kiili Spordikompleks)
   - IKEA (Kurna)
   - Selver (Kurna)
   - Decathlon (Kurna)
4. У каждой метки можно задать название и короткое описание — **они будут видны посетителям сайта**, так что подписи стоит написать по-эстонски и аккуратно.
5. Открыть доступ: **«Поделиться» → «Все, у кого есть ссылка» → Просмотр**. Без этого шага карта на сайте не отобразится.
6. Затем **⋮ (три точки) → «Встроить на мой сайт»** и скопировать выданный HTML.

**Что прислать мне:** этот HTML целиком, либо только ссылку вида
`https://www.google.com/maps/d/embed?mid=......`

Дальше я вставляю её на страницу — правок в коде минимум.

**Почему рекомендую именно этот вариант:** после встраивания заказчик может **сам** двигать, добавлять и переименовывать метки прямо в My Maps — изменения появятся на сайте сразу, без разработчика и без публикации. По сути это единственный пункт из списка Индрека, который сразу становится редактируемым им самим.

---

## Вариант B — Google Maps API с ключом

Полный контроль над видом карты (свои иконки, стиль, всплывающие окна), но дороже в обслуживании.

**Что нужно:**

1. Аккаунт в **Google Cloud Console** с **привязанной картой оплаты** (у Google есть бесплатный месячный лимит, но карта обязательна).
2. Создать проект → включить **Maps JavaScript API**.
3. Создать **API-ключ** и обязательно ограничить его по HTTP-referrer, разрешив только:
   - `magnoolia.estlanda.ee/*`
   - `magnoolia.ee/*` (на будущее)
4. Прислать мне ключ.

**Что важно понимать заранее:**
- Ключ Maps виден в HTML-коде страницы — для этого типа ключей это нормально и предусмотрено Google, но защищает его именно ограничение по домену из п. 3. Без ограничения ключом смогут пользоваться посторонние **за ваш счёт**.
- Расход считается по загрузкам карты. При обычном трафике сайта бесплатного лимита хватает, но за этим нужно следить.
- Метки будут заданы в коде, поэтому каждое изменение — задача разработчику. В отличие от варианта A.

---

## Вариант C — OpenStreetMap (без Google)

Ничего от заказчика не требуется: ни аккаунта, ни ключа, ни оплаты. Все 7 меток ставятся сразу, карта интерактивная.

**Минус:** это не Google — другая графика и подписи, и на странице добавится ~40 КБ JavaScript.

Если для заказчика важна именно узнаваемость Google Maps — этот вариант не подходит. Если важнее «просто чтобы работало и было бесплатно» — он самый быстрый.
